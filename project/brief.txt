Prompt Strategy Notes (for Claude Design sessions)
When prompting for each section individually:
1. Always lead with brand context: “Event ConnecTD is a B2B marketplace for Travel
Directors in the MICE industry. Brand colors: navy #185FA5, dark navy #0D2137, teal
#1D9E75.”
2. Specify the section number and purpose from this doc first
3. Paste the Content block verbatim as the copy to use
4. End with Design Notes as constraints
5. Request desktop + mobile view if the tool supports it
6. Keep section prompts isolated — one prompt per section for cleaner output
Priority order for design sessions:
1. Hero (Section 2) — most important, sets the visual tone
2. How It Works (Section 7) — high-converting, needs to be clear
3. Value Props + Platform Preview (Section 5) — central pitch
4. Savings Calculator (Section 6) — interactive proof
5. Service Category Tabs (Section 3) — educational
6. All others to follow
